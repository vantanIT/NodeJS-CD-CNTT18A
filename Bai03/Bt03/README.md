# Bài 3: Thao tác tập tin bằng Node.js

## 1. Mô tả bài thực hành
Bài thực hành sử dụng module `fs` có sẵn trong Node.js để thực hiện các thao tác tạo, đọc và ghi nối thêm nội dung vào tập tin.

## 2. Nội dung thực hiện
- Tạo tập tin `thongtin.txt` chứa họ tên và mã sinh viên.
- Đọc và hiển thị nội dung tập tin trên Terminal.
- Sử dụng phương thức `appendFile()` để ghi nối thêm tên lớp vào cuối tập tin.
- Đọc lại tập tin và hiển thị nội dung sau khi cập nhật.

## 3. Công nghệ sử dụng
- Node.js
- Module `fs` (File System)

## 4. Cách chạy chương trình
Mở Terminal tại thư mục chứa file JavaScript và chạy lệnh:

```bash
node bai03.js
```

## 5. Kết quả
Chương trình tạo tập tin `thongtin.txt`, ghi thông tin sinh viên, bổ sung tên lớp và hiển thị nội dung trước và sau khi cập nhật trên Terminal.

## 6. Ảnh minh chứng
Bổ sung các ảnh sau:
1. Mã nguồn chương trình `bai03.js`.
2. Kết quả chạy lệnh `node bai03.js` trên Terminal.
3. Nội dung tập tin `thongtin.txt` sau khi cập nhật.
