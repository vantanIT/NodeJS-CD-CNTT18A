
# Bài 02 - Ứng dụng Node.js đầu tiên

## Mô tả
Sử dụng module http có sẵn trong Node.js để tạo HTTP Server.
Server chạy tại cổng 3000 và trả về trang HTML hiển thị họ tên
và mã sinh viên.

## Công nghệ
- Node.js
- Module http
- HTML

## Cách chạy
1. Cài đặt Node.js.
2. Mở Terminal tại thư mục chứa file myFirstNode.js.
3. Chạy lệnh:

   node myFirstNode.js

4. Mở trình duyệt tại:

   http://localhost:3000
